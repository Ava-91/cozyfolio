# Security Policy

## Supported Versions

Security updates are provided for the latest version of Cozyfolio.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅ Yes |
| Older versions | ❌ No |

## Reporting a Vulnerability

If you discover a security vulnerability in Cozyfolio, please report it responsibly.

You can report issues by opening a private security advisory on GitHub:

https://github.com/Ava-91/cozyfolio/security/advisories

Please include:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any relevant screenshots, logs, or examples

I will review reported vulnerabilities as soon as possible and provide updates once the issue has been investigated.

## Security Updates

Security fixes are released through GitHub commits and dependency updates.

Dependencies are regularly reviewed using GitHub Dependabot and npm security audits.
